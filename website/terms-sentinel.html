Sentinel terms

Last updated October 2, 2026. This is a starter policy. Replace it with your real rules before you publish.

1. What Sentinel is

Sentinel is a Discord moderation bot. It only works inside servers that invite it. Using the bot means you agree to these terms and to Discord’s own rules.

2. Who may use it

Server owners and staff may configure Sentinel. Members are covered by the filters and logs the server turns on. Do not use Sentinel to harass anyone.

3. Data

Sentinel may store server IDs, channel IDs, role IDs, warning counts, and short log text needed to run moderation. It does not ask for passwords or direct messages outside the server features you enable.

4. Staff duties

Server staff are responsible for the filter lists they write and for how they use warnings or timeouts. Sentinel is a tool, not a replacement for a human moderator.

5. Availability

The bot may go offline for fixes. Features can change. We may remove access if a server uses the bot to break Discord’s Terms of Service.
